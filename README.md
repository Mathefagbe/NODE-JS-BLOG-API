# 📘 Blog API – Node.js

A RESTful API for a blogging platform built with **Node.js** and **Express**. This backend service provides endpoints for managing blog posts, user accounts, and comments. Ideal for use with any frontend (React, Vue, etc.) or mobile app.

---

## ✨ Features

- ✅ User registration and authentication (JWT)
- 📝 Create, read, update, and delete (CRUD) for blog posts
- 💬 Commenting system for posts
- 🔐 Role-based access control (Admin, Author, Reader)
- 🛡️ Secure password hashing with bcrypt
- 📦 MongoDB with Mongoose ODM
- ⚙️ Environment configuration with dotenv
- 📁 Modular and scalable folder structure

---

## 🧰 Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB + Mongoose**
- **JWT** (JSON Web Tokens)
- **bcrypt**
- **dotenv**
